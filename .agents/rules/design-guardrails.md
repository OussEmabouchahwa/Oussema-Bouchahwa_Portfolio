# Design guardrails
- Match `docs/design-reference.html` and `docs/DESIGN_SYSTEM.md`. When they disagree, DESIGN_SYSTEM wins; ask if unclear.
- One accent: `--tape`. Steel and sage only for clips and the "passing" status.
- One italic serif word per heading, never more.
- Timecodes are `HH:MM:SS:FF`, mono, tabular numerals.
- Empty media slots always show crop marks, the "Drop …" hint and the file path.
- Banned: decorative gradients, glass, blur, glow, neon, purple or indigo, emoji, icon-in-circle tiles, pills everywhere, stock photos, lorem ipsum.
- A visual change is done only after a screenshot shows it at 390 and 1440.
