# Design review
For each screenshot (390, 768, 1440):
1. Clipped or overlapping text? Horizontal scroll?
2. Fonts: Geist, Geist Mono, Instrument Serif italic only where specified.
3. Only one accent (tape). Italic word count per heading = 1.
4. Signature elements present: timecodes, sequence bar with playhead, crop marks on empty slots, tracks.
5. Any banned style? (see DESIGN_SYSTEM "Bans")
6. Spacing rhythm: section paddings, gaps, alignment of repeated cards.
Fix, re-screenshot once, report what changed.
